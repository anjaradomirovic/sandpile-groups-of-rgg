# Sandpile Groups of Random Geometric Graphs

An early-stage research project on the algebraic structure of **sandpile groups** of **random geometric graphs**: random graphs where nodes are placed in space and connected when they are close, as in many real networks, including the wiring of the brain.

For classical random graphs the distribution of these groups is well understood, but spatial graphs break the independence assumptions behind those results. This project explores what happens there, computationally.

> Work in progress. The project is unpublished, so details and results will be added later.
